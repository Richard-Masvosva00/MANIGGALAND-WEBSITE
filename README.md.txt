
# Maniggaland Music Studio

## Project Description
Maniggaland Music Studio is a music studio website developed
using HTML5 and external CSS3.

The website introduces the studio, explains its services,
provides information about the studio, and allows visitors
to view contact details and complete an enquiry form.
